2 · Free-tier unlock ladders

Free users start with all easy questions. Medium unlocks in batches as you solve easy; hard unlocks in batches as you solve medium, with a per-track cap. Thresholds differ by track type (the conceptual/MCQ tracks ask for a few more solves, since each MCQ is lower-effort than running & debugging code). Pro & Elite have no gating — every difficulty is open.

Code tracks

SQL · Python · Pandas · Statistics  (unlock_profile = code)

Unlock mechanics
  • Per track, independent. The ladder runs separately for each track — solving SQL easy questions doesn't unlock Python medium.
  • Paths don't change unlocks. A learning path is just an ordered grouping of existing practice questions — solving one advances the same per-track thresholds as solving from the practice catalog. Completing a path unlocks nothing extra.
  • Locked behaves by track type. A locked code question is inaccessible; a locked conceptual/MCQ question returns 200 with locked: true — the stem shows, but options + explanation are hidden. Submitting any locked question → 403.
  • The cap is a hard ceiling. Free hard is capped at 8 (code) / 5 (MCQ) regardless of how many medium you solve — clearing the cap is a Pro upgrade, not a grind.
